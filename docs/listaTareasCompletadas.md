**Como** usuario de la agenda,
**quiero** poder listar las tareas que ya he completado,
**para** revisar las actividades que he terminado y llevar un control de mi progreso.

---

### Descripción:
La aplicación debe permitir al usuario visualizar una lista con todas las tareas marcadas como completadas.

---

### Criterios de aceptación

- [ ] El sistema debe mostrar una lista de todas las tareas con estado **“completada”**.
- [ ] Cada tarea listada debe mostrar al menos su **texto**, **fecha de creación** y **fecha de finalización** (si aplica).
- [ ] Si no existen tareas completadas, el sistema debe mostrar un mensaje informativo:
  > “No hay tareas completadas.”
- [ ] El usuario debe poder acceder a esta funcionalidad a través de un menú de consola.
